# 2026-10-24

## u-tools 项目升级到 JDK 25 + Spring Boot 4.1.2

- **升级范围**：Spring Boot 2.1.0 → 4.1.2（当前最新稳定版），Java 8 → 25，所有依赖升至最新
- **依赖版本**：spring-boot-admin 4.1.4、mysql-connector-j 26.10.0（坐标从 mysql:mysql-connector-java 迁移到 com.mysql:mysql-connector-j）、druid 1.2.28、fastjson→fastjson2 2.0.66、guava 33.7.2-jre、commons-lang3 3.21.0、lombok 1.18.48、Maven wrapper 3.5.4→3.9.9
- **代码迁移**：
  - javax.servlet → jakarta.servlet（IndexController）
  - com.mysql.jdbc.Connection/PreparedStatement → java.sql.*（6 个 dbTools 类）；驱动类改 com.mysql.cj.jdbc.Driver
  - fastjson 1.x → fastjson2（ConfigData）
  - Druid API：MySqlSelectQueryBlock.Limit → com.alibaba.druid.sql.ast.SQLLimit
  - SqlController 的 guava Function/Lists.transform → 原生 for 循环（同时移除 javax.annotation.Nullable）
  - Spring StringUtils.isEmpty（Spring 7 已删除）→ commons-lang3 StringUtils（ConvertUtil）
  - JUnit4 → JUnit5（UToolsApplicationTests）
- **配置变更**：
  - spring-boot-starter-web → spring-boot-starter-webmvc（Boot 4 新命名）；新增 spring-boot-starter-thymeleaf（原来靠 admin 传递依赖，Boot 4 下已无）
  - application.properties：spring.resources.* → spring.web.resources.*
  - 仓库 URL http → https（maven.aliyun.com/repository/public）
  - 移除重复的 spring-boot-maven-plugin 和老 surefire 2.7.1
- **关键坑**：
  1. JDK 23+ 默认禁用注解处理器 → pom 中 maven-compiler-plugin 需配 `<proc>full</proc>`，否则 Lombok 失效
  2. WorkBuddy 沙箱会给 java 子进程注入 SERVER_PORT=5539 覆盖 server.port，冒烟测试需显式 -Dserver.port=18887
- **验证结果**：mvn clean package（含测试）BUILD SUCCESS；contextLoads 1/1 通过；JDK 25.0.2 下启动应用，Tomcat 11.0.27 正常启动，/db/index HTTP 200
- 本机 JDK：D:\Tools\jdk-25.0.2（用户手动下载），构建命令：JAVA_HOME=D:/Tools/jdk-25.0.2 mvn clean package
